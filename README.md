One pickup line, a single line of at most 200 characters, in the voice of a robot trying to charm someone — entered in [The Robot Pickup Line Championship](https://make.fun/c/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun. The joke grows out of being a machine: the robot's own sensors do the flirting, and the imperfection in its reading is just a rounding error.

## The line

> My sensors report you're 98% perfect. The other 2% is a rounding error I'll gladly ignore.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
